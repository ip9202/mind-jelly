# Mind Jelly (마음 젤리)

> 스트레스는 귀여움으로 녹는다

감정을 먹는 AI 캐릭터 "냠냠이"와 함께하는 힐링 다이어리 앱.

## 프로젝트 개요

Mind Jelly는 사용자가 자신의 감정을 시각화하고, 냠냠이 캐릭터에게 감정 구슬을 먹이면서 정화하는 과정을 통해 심리적 안정을 얻을 수 있는 힐링 앱입니다.

### 주요 기능

- **감정 기록하기**: 매일의 감정을 9가지 감정 카테고리로 기록
- **냠냠이와 소통**: 감정 구슬을 먹인 냠냠이의 반응 보기
- **감정 시각화**: 주간 감정 트렌드와 분포를 인터랙티브 차트로 확인
- **개인화된 인사이트**: 감정 패턴 분석과 힐링 조언 받기
- **소셜 기능**: 친구들과 감정 구슬 공유하기

## 기술 스택

### 프레임워크
- **Next.js 16** - React App Router
- **React 19** - UI 라이브러리
- **TypeScript** - 타입 안전성

### 스타일링
- **Tailwind CSS v4** - 유틸리티 퍼스트 CSS
- **CSS Modules** - 컴포넌트 스코프 스타일
- **Framer Motion** - 애니메이션

### 데이터 시각화
- **Recharts** - 감정 트렌드 차트

- **React Hooks** - 로컬 상태 관리
- **LocalStorage** - 클라이언트 데이터 저장

### 테스팅
- **Jest** - 테스트 프레임워크
- **React Testing Library** - 컴포넌트 테스트


## 감정 시각화

### 감정 통계 바텀시트 (SPEC-UI-002)
- 홈 화면의 차트를 바텀시트 모달로 분리하여 모바일 세로 공간 최적화
- "감정 통계 보기" 버튼 탭으로 하단에서 슬라이드업
- 5가지 닫기 방법: 백드롭 탭, 스와이프 다운, ESC 키, X 버튼, CTA 토글
- 부드러운 슬라이드 애니메이션과 접근성 지원

### 주간 감정 트렌드 차트 (SPEC-UI-001)
- 최근 7일간의 감정 변화 추이를 라인 차트로 표시
- 각 감정은 9개 감정 컬러 시스템 색상으로 구분
- 호버/터치로 상세 정보 툴팁 확인

### 감정 분포 도넛 차트 (SPEC-UI-001)
- 전체 감정 중 각 감정의 비율을 도넛 차트로 시각화
- 섹터 클릭으로 해당 감정의 일별 상세 내역 확인
- 중앙에 가장 빈번한 감정 표시

### 개인화된 인사이트 (SPEC-UI-001)
- 가장 자주 정화한 감정 순위
- 감정 패턴 변화 감지
- 연속 정화 일수 스트릭

## 브랜드 디자인

### 디자인 철학
"스트레스는 귀여움으로 녹는다"

감정 분석 용어("관리", "분석", "측정") 대신 힐링 용어("삼키다", "정화", "토닥토닥", "먹다")를 사용합니다.

### 감정 색상 시스템

| 감정 | 색상 | 톤 |
|------|------|-----|
| Happy (행복) | yellow | bright |
| Loved (사랑받음) | pink | warm |
| Satisfied (만족) | green | fresh |
| Excited (신남) | orange | vibrant |
| Calm (평온) | teal | cool |
| Sad (슬픔) | blue | melancholy |
| Angry (화남) | red | intense |
| Anxious (불안) | purple | uneasy |
| Tired (피곤) | gray | neutral |

## 접근성

WCAG 2.1 AA 수준의 접근성을 준수합니다:

- 색상 대비율 4.5:1 이상 (텍스트)
- 키보드 네비게이션 지원 (Tab, ESC, 화살표 키)
- 포커스 트랩 (모달/바텀시트 내부 Tab 순환)
- 포커스 복원 (모달 닫힐 때 트리거 버튼으로 포커스 반환)
- 터치 타겟 크기 44x44px
- `prefers-reduced-motion` 지원
- 스크린 리더 대체 텍스트 제공
- ARIA 속성 (`aria-modal`, `aria-label`, `aria-hidden`)
