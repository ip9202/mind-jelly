# 마음 젤리 인앱 광고 수익화 전략

생성일: 2026-05-11
상태: 설계 완료, 구현 보류

---

## 1. 개요

마음 젤리 서비스의 핵심 가치인 "감정 정화 경험"을 해치지 않으면서 자연스러운 광고 통합을 통한 수익화 전략입니다.

### 목표
- **수익 창출**: DAU 1,000명 기준 월 ~27,000원 예상
- **UX 최소화**: 감정 정화 흐름에 최소한으로 개입
- **전환 유도**: 보상형 광고로 부가 서비스 노출

### 타겟 사용자
- 20-40대 직장인/대학생
- 일상 스트레스 관리 필요
- 디지털 네이티브 (광고 수용성 높음)

---

## 2. 광고 UX 흐름

### 현재 사용자 흐름
```
감정 입력 → AI 분석 → 젤리 생성 → 구슬 삼키기 → Satisfied 상태 → 결과 공유
```

### 광고 통합 지점
```
감정 입력 → AI 분석 → 젤리 생성 → 구슬 삼키기 → Satisfied 상태 
                                              ↓
                                    [광고 자연 삽입 지점]
                                              ↓
                                    추가 혜택 선택 (광고 or 결제)
```

## 3. 광고 유형별 배치 전략

### 3.1 전면형 (인터스티셜) — 메인 광고

| 항목 | 내용 |
|------|------|
| **배치 화면** | 결과 화면 진입 전 |
| **타이밍** | 젤리가 구슬을 다 삼킨 후 (Satisfied 상태) |
| **트리거** | Satisfied 상태 진입 시 자동 |
| **복귀 버튼** | 5초 후 스킵 가능 |
| **광고 길이** | 15~30초 |

### 3.2 배너 광고 — 보조 수익

| 항목 | 내용 |
|------|------|
| **배치 위치** | 결과 화면 하단만 (권장) |
| **사이즈** | 320x50 (모바일 표준) |
| **간섭 정도** | 낮음 (다른 화면은 사용 안 함) |

### 3.3 보상형 (리워드) — 전환 유도

| 항목 | 내용 |
|------|------|
| **배치 화면** | 결과 화면 |
| **CTA 버튼** | "📊 더 자세한 분석 보기" |
| **보상 내용** | 주간 패턴 리포트 / 키워드 / 한정판 스킨 |
| **광고 길이** | 30초 (보상형 권장) |

## 4. 광고 콘텐츠 전략

### 4.1 감정별 카테고리 매칭

| 감정 타입 | 광고 카테고리 예시 | 전환율 기대 |
|-----------|-------------------|-------------|
| 분노 | 스트레스 해소 제품, 명상 앱 | 높음 |
| 슬픔 | 엔터테인먼트, 음악 서비스 | 중간 |
| 불안 | 금융, 보험 서비스 | 중간 |
| 지침 | 자기계발, 교육 콘텐츠 | 낮음 |
| 허무 | 라이프스타일, 쇼핑 | 낮음 |

### 4.2 광고 빈도 제어

| 유저 상태 | 광고 빈도 | 이유 |
|-----------|-----------|------|
| 신규 유저 (첫 3회) | **0회** | 온보딩 경험 보호 |
| 일반 유저 | 세션당 **1회** 전면형 | 광고 피로도 방지 |
| 헤비 유저 (일 5회 이상) | 세션당 **2회** | 수익 최대화 |

## 5. 보상 메커니즘

### 보상 항목

**보상 A: 주간 감정 패턴 리포트**
- 지난 7일간 감정 분포 (원 그래프)
- 가장 자주 나타난 감정 TOP 3
- 감정 변화 추세선
- 요일별/시간별 패턴

**보상 B: 오늘의 감정 키워드**
- 감정 입력에서 추출한 핵심 키워드 5개
- 키워드 빈도 분석
- 연관어 추천

**보상 C: 한정판 젤리 스킨**
- 특별 테마 젤리 (곰돌이, 고양이, 판다 등)
- 24시간만 사용 가능
- 광고 시청마다 새로운 스킨 해금

## 7. A/B 테스트 계획

### 테스트 변수

| 변수 | 옵션 A | 옵션 B | 측정 지표 |
|------|--------|--------|-----------|
| 광고 타이밍 | Satisfied 즉시 | 2초 딜레이 | 이탈률, 완료율 |
| 스킵 버튼 | 5초 후 표시 | 3초 후 표시 | 광고 시청 완료율 |
| 배너 위치 | 결과 화면만 | 홈 + 결과 | 클릭률, 세션 시간 |
| CTA 문구 | "더 보기" | "광고 보고 받기" | 전환율 |

### 성과 지표

| 지표 | 정의 | 목표치 |
|------|------|--------|
| 광고 완료율 | 광고를 끝까지 시청한 비율 | 70% 이상 |
| 이탈륨 | 광고 중 이탈한 비율 | 30% 이하 |
| 전환율 | 보상형 CTA 클릭 비율 | 10% 이상 |
| 세션 시간 | 평균 세션 지속 시간 | 2분 이상 유지 |

## 11. 수익화 UX 원칙

### 원칙 1: 감정 정화 흐름 방지하지 않기
- 광고는 젤리가 구슬을 다 삼킨 후(Satisfied 상태)에만 표시
- 감정 입력 과정에는 광고 없음

### 원칙 2: 가치 교환 명확히 하기
- 보상형 광고: "광고 시청하고 추가 리포트 받기"
- 인앱 결제: 혜택을 명확히 표시

### 원칙 3: 프라이버시 지키기
- 광고/결제 데이터는 감정 데이터와 분리
- 개인정보 제3자 공유 없음

## 12. 추천 로드맵

### Phase 1: 출시 후 1개월 (유저 확보)
- **보상형 광고만** 도입
- 무료 서비스로 사용자 확보
- 데이터 수집 및 튜닝

### Phase 2: 출시 후 2~3개월 (단건 결제)
- **프리미엄 스킨** 출시
- **상세 리포트** 단건 판매
- 사용자 피드백 수집

### Phase 3: 출시 후 4~6개월 (구독 론칭)
- **월간 멤버십** 출시
- **무료 체험** 프로모션
- 충성 유저 대상 정기결제 전환
