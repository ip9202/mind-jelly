## 수용 시나리오

### AC-VIS-001: 주간 감정 트렌드 차트 렌더링

**Given** 사용자가 최근 7일간 감정 정화 기록이 있고
**When** 홈 화면의 감정 리포트가 표시되면
**Then** 최근 7일간의 감정 변화 추이 라인 차트가 glass-card 컨테이너 내에 렌더링된다

**검증 기준**:
- X축에 월-일 요일 라벨이 표시된다
- 각 감정 선은 `EMOTION_COLORS`의 색상을 사용한다
- 데이터 포인트가 감정 빈도수에 정확히 위치한다
- 차트 컨테이너에 `glass-card rounded-3xl` 클래스가 적용된다

---

### AC-VIS-002: 데이터 없는 상태 처리

**Given** 사용자의 감정 정화 기록이 없고 (또는 첫 방문)
**When** 홈 화면의 감정 리포트가 표시되면
**Then** 빈 차트 대신 격려 메시지와 가이드 UI가 표시된다

**검증 기준**:
- 빈 차트(빈 화면)가 표시되지 않는다
- "오늘 감정을 정화해볼까?" 유도 메시지가 표시된다
- CTA 버튼("감정 표현하기")이 정상 동작한다
- 기존 `idle` 상태 UI와 일관된 디자인

---

### AC-VIS-003: 감정 분포 도넛 차트

**Given** 사용자가 다수의 감정 정화 기록을 가지고 있고 (3개 이상 감정 타입)
**When** 감정 리포트의 분포 차트가 렌더링되면
**Then** 각 감정의 비율이 도넛 차트 형태로 시각화된다

**검증 기준**:
- 9개 감정 각각의 비율이 퍼센트로 표시된다
- 각 섹터는 `EMOTION_COLORS`의 색상을 사용한다
- 중앙에 가장 빈번한 감정의 아이콘과 퍼센트가 표시된다
- 5% 미만 감정은 "기타"로 통합된다
- 전체 퍼센트 합이 100%이다

---

### AC-VIS-004: 시각적 계층 구조

**Given** 감정 리포트가 화면에 표시되고
**When** 리포트가 완전히 렌더링되면
**Then** 3단계 시각적 계층이 순서대로 나타난다

**검증 기준**:
- 상단: 주요 감정 아이콘 + 한 줄 요약 메시지
- 중간: 차트 영역 (트렌드 차트 + 분포 차트)
- 하단: 개인화된 조언 텍스트
- 각 레이어 간 시각적 구분이 명확하다
- `font-gamja` (본문)과 `font-jakarta` (라벨)가 올바르게 적용된다

---

### AC-VIS-005: 차트 인터랙션

**Given** 주간 트렌드 차트가 화면에 표시되고
**When** 사용자가 특정 데이터 포인트를 호버(또는 터치)하면
**Then** 해당 날짜의 감정 상세 정보가 툴팁으로 표시된다

**검증 기준**:
- 툴팁에 날짜, 감정명, 빈도수가 포함된다
- 툴팁은 300ms 이내에 나타난다
- 툴팁 감정 색상이 해당 감정의 `EMOTION_COLORS`와 일치한다
- 터치 환경에서도 정상 동작한다

---

### AC-VIS-006: 도넛 차트 인터랙션

**Given** 감정 분포 도넛 차트가 화면에 표시되고
**When** 사용자가 특정 감정 섹터를 클릭(또는 탭)하면
**Then** 해당 감정의 일별 상세 내역이 슬라이드업 패널로 표시된다

**검증 기준**:
- 슬라이드업 패널이 부드러운 애니메이션으로 나타난다
- 패널에 해당 감정의 일별 상세 데이터가 포함된다
- 패널 외부 영역 클릭 시 패널이 닫힌다
- 패널 내용이 브랜드 보이스(반말, 힐링 용어)를 준수한다

---

### AC-VIS-007: 애니메이션 시퀀스

**Given** 감정 정화가 완료되어 리포트 상태로 전이되고
**When** 감정 리포트가 화면에 나타나면
**Then** 정의된 애니메이션 시퀀스가 순차적으로 실행된다

**검증 기준**:
- 리포트 카드: 1000ms fade-in (기존 동작 유지)
- 차트 영역: 1500ms draw-in 애니메이션
- 도넛 차트: 1200ms reveal 애니메이션
- 인사이트 텍스트: 지연 fade-in (기존 동작 유지)
- 각 애니메이션이 이전 애니메이션 완료 후 시작되지 않고 자연스럽게 겹친다

---

### AC-VIS-008: 모션 감소 설정 대응

**Given** 사용자의 기기에 `prefers-reduced-motion`이 활성화되어 있고
**When** 감정 리포트가 화면에 나타나면
**Then** 모든 애니메이션이 즉시 완료 상태로 표시된다

**검증 기준**:
- fade-in 없이 즉시 표시
- draw-in 없이 차트가 완성된 형태로 즉시 표시
- reveal 없이 도넛 차트가 완성된 형태로 즉시 표시
- 기능적 동작에는 영향이 없다

---

### AC-VIS-009: 접근성 - 스크린 리더

**Given** 스크린 리더가 활성화된 환경이고
**When** 감정 리포트가 화면에 표시되면
**Then** 모든 차트 데이터가 스크린 리더를 통해 접근 가능하다

**검증 기준**:
- 차트 영역에 `role="img"` 및 `aria-label` 속성이 포함된다
- 차트 데이터를 설명하는 대체 텍스트가 제공된다
- `aria-live="polite"` 속성으로 데이터 변경 시 스크린 리더에 알림
- 대체 텍스트 테이블이 시각적으로 숨겨진 상태로 존재한다
- 키보드 Tab 키로 차트 요소 간 이동이 가능하다

---

### AC-VIS-010: 색상 대비 접근성

**Given** 감정 리포트가 화면에 표시되고
**When** 차트 내 텍스트 및 시각적 요소를 확인하면
**Then** WCAG 2.1 AA 수준의 색상 대비율을 충족한다

**검증 기준**:
- 텍스트 요소: 최소 4.5:1 대비율
- 시각적 요소(차트 선, 영역): 최소 3:1 대비율
- 라이트 모드와 다크 모드 모두에서 충족
- 감정 색상이 배경과 충분한 대비를 가진다

---

### AC-VIS-011: 개인화 인사이트

**Given** 사용자의 감정 데이터가 7일 이상 축적되어 있고
**When** 감정 리포트의 인사이트 레이어가 표시되면
**Then** 개인화된 감정 인사이트가 표시된다

**검증 기준**:
- 가장 자주 정화한 감정 상위 3개가 순위로 표시된다
- 감정 패턴 변화 감지 메시지가 표시된다 (예: "이번 주 슬픔이 줄었어!")
- 연속 정화 일수가 불꽃 아이콘과 함께 표시된다
- 사용자 이름이 포함된 개인화 메시지가 표시된다
- 모든 메시지가 반말과 힌알 용어를 사용한다

---

### AC-VIS-012: 반응형 레이아웃

**Given** 다양한 화면 크기의 기기에서 서비스를 이용하고
**When** 감정 리포트가 렌더링되면
**Then** 화면 크기에 맞게 레이아웃이 조정된다

**검증 기준**:
- 모바일 (320-428px): 차트가 세로로 스택 배치, 전체 너비
- 태블릿 (429-768px): 차트 2열 배치 가능
- `max-w-md` 제약이 유지된다
- 차트 크기가 컨테이너 너비에 비례하여 조정된다
- 텍스트가 줄바꿈 없이 가독성을 유지한다

---

### AC-VIS-013: 기존 상태 머신 호환성

**Given** 홈 페이지의 기존 `uiState` 상태 머신이 동작하고
**When** 감정 리포트 UI가 개선된 후에도
**Then** 모든 기존 상태 전이가 정상 동작한다

**검증 기준**:
- `idle` → `input` 전이 정상 (CTA 버튼 클릭)
- `input` → `report` 전이 정상 (감정 분석 완료)
- `report` → `idle` 전이 정상 (리포트 확인 후)
- `EMOTION_COLORS[lastEmotion]` 동적 색상 전환이 유지된다
- 기존 CTA 버튼("감정 표현하기") 동작이 보존된다
- `disabled={uiState === 'report'}` 버튼 비활성화 로직 유지

---

### AC-VIS-014: 성능 기준

**Given** 감정 리포트가 포함된 홈 페이지가 로딩되고
**When** Lighthouse 성능 측정을 실행하면
**Then** 다음 성능 기준을 충족한다

**검증 기준**:
- Lighthouse Performance 점수 85점 이상
- Recharts 동적 import로 인한 초기 로딩 지연 200ms 이하
- 차트 렌더링 후 애니메이션 프레임레이트 60fps 유지
- gzip 기준 Recharts 추가 번들 사이즈 50KB 이하
- 기존 페이지 로딩 시간 대비 20% 이하 증가

---

### AC-VIS-015: 다크 모드 동작

**Given** 사용자의 기기가 다크 모드로 설정되어 있고
**When** 감정 리포트가 화면에 표시되면
**Then** 모든 차트 요소가 다크 모드에 최적화되어 표시된다

**검증 기준**:
- glass-card 배경이 다크 모드 색상으로 전환된다
- 차트 축 및 라벨 텍스트가 밝은 색상으로 표시된다
- 감정 색상이 다크 배경에서 충분한 대비를 가진다
- 툴팁이 다크 모드에서도 가독성이 유지된다
- 애니메이션이 다크 모드에서도 동일하게 동작한다

## 엣지 케이스

### EC-001: 단일 감정만 있는 경우

**상황**: 사용자가 한 가지 감정만 정화한 경우
**기대 동작**: 도넛 차트가 100% 단일 색상으로 표시, "오직 한 가지 감정만?" 격려 메시지

### EC-002: 모든 감정이 5% 미만인 경우

**상황**: 감정이 매우 골고루 분포된 경우 (20개 이상 감정 타입, 이론적)
**기대 동작**: "기타" 통합 없이 모든 감정이 개별 섹터로 표시

### EC-003: 하루에 여러 번 정화한 경우

**상황**: 같은 날 다수의 감정 정화 기록이 있는 경우
**기대 동작**: 일별 집계가 올바르게 합산되어 트렌드 차트에 반영

### EC-004: 데이터가 7일 미만인 경우

**상황**: 신규 사용자로 데이터가 부족한 경우
**기대 동작**: 있는 데이터만큼만 차트에 표시, 나머지 일수는 빈 상태로

### EC-005: 로컬 스토리지 데이터 손상

**상황**: 감정 데이터가 손상되었거나 읽을 수 없는 경우
**기대 동작**: graceful fallback으로 기본 리포트 UI 표시, 에러 로깅
