# SPEC-AD-002: 인수 기준

## Given/When/Then 시나리오

### REQ-AD-006: 보상형 광고 모달

**시나리오 1: 정상 보상 흐름**
- **Given** 홈 화면이 `report` 상태임
- **And** SPEC-AD-001의 빈도 제어기가 보상형 광고를 허용함
- **When** 사용자가 "더 자세한 분석 보기" CTA 버튼을 클릭함
- **Then** 보상 유형 선택 모달이 표시됨 (A/B/C)
- **When** 보상 A를 선택하고 30초 광고가 재생됨
- **And** 광고가 끝까지 재생됨
- **Then** 주간 리포트가 생성되어 모달 내에 표시됨

**시나리오 2: 광고 중도 포기**
- **Given** 보상형 광고가 재생 중임
- **When** 사용자가 뒤로가기 또는 시스템 뒤로가기로 광고를 종료함
- **Then** 보상이 지급되지 않고 모달이 닫힘

**시나리오 3: 광고 로드 실패**
- **Given** 네트워크 오류로 보상형 광고 로드가 실패함
- **When** 사용자가 보상 유형을 선택함
- **Then** "잠시 후 다시 시도해주세요" 메시지가 표시됨

### REQ-AD-007: 보상 A - 주간 감정 패턴 리포트

**시나리오 1: 충분한 데이터**
- **Given** 지난 7일간 감정 기록이 10회 존재함
- **When** 보상 A가 지급됨
- **Then** 9개 감정별 분포 원 그래프가 표시됨
- **And** TOP 3 감정이 카드로 표시됨
- **And** 7일 감정 추세선이 표시됨
- **And** 요일별/시간대별 패턴이 표시됨

**시나리오 2: 데이터 부족**
- **Given** 지난 7일간 감정 기록이 2회만 존재함
- **When** 보상 A가 지급됨
- **Then** "데이터가 더 모이면 더 정확한 리포트를 받을 수 있어요" 안내가 표시됨
- **And** 가능한 범위 내에서 리포트가 생성됨

### REQ-AD-008: 보상 B - 오늘의 감정 키워드

**시나리오 1: 정상 키워드 추출**
- **Given** 오늘 "회사에서 스트레스 받아서 지쳤어" 감정을 입력함
- **When** 보상 B가 지급됨
- **Then** 키워드 카드 5개가 표시됨 (예: 회사, 스트레스, 지침, 피곤, 힘듦)
- **And** 각 키워드에 빈도수가 표시됨

**시나리오 2: 짧은 입력**
- **Given** 오늘 "힘들다" 한 단어만 감정 입력함
- **When** 보상 B가 지급됨
- **Then** 감정명 기반 파생 키워드로 보충하여 5개 카드가 표시됨

### REQ-AD-009: 보상 C - 한정판 젤리 스킨

**시나리오 1: 스킨 해금**
- **Given** 현재 활성 스킨이 없음
- **When** 보상 C가 지급됨
- **Then** 무작위 스킨이 해금되고 축하 애니메이션이 표시됨
- **And** 홈 화면 젤리가 해당 스킨으로 교체됨
- **And** 스킨 이름과 남은 시간이 표시됨

**시나리오 2: 스킨 교체**
- **Given** '곰돌이' 스킨이 활성화되어 있음 (남은 시간 12시간)
- **When** 새로운 보상 C로 '고양이' 스킨이 해금됨
- **Then** 젤리가 '고양이' 스킨으로 교체됨
- **And** 타이머가 24시간으로 리셋됨

**시나리오 3: 24시간 만료**
- **Given** '판다' 스킨이 23시간 59분 전에 해금됨
- **When** 24시간이 경과함
- **Then** 스킨이 비활성화되고 기본 젤리로 복원됨

**시나리오 4: 앱 재시작 시 만료 확인**
- **Given** 어제 스킨이 해금되어 expiresAt이 과거 시간임
- **When** 앱이 시작됨
- **Then** 만료된 스킨이 비활성화되고 기본 젤리로 복원됨

### REQ-AD-010: 보상 상태 관리

**시나리오 1: 상태 영속화**
- **Given** 사용자가 보상 B를 받아 키워드가 저장됨
- **When** 앱을 종료하고 재시작함
- **Then** 이전에 받은 키워드가 rewardStore에 복원됨

**시나리오 2: 활성 스킨 타이머 재개**
- **Given** 스킨 해금 후 5시간 경과한 상태에서 앱 종료
- **When** 앱을 재시작함
- **Then** 남은 19시간 타이머가 표시되고 스킨이 유지됨

## 엣지 케이스

1. **보상 모달 중 report->idle 전환**: 모달이 열린 상태에서 report 자동 복귀 타이머가 만료되면 타이머를 일시정지하고 모달이 닫힐 때까지 대기
2. **빈도 제어 초과**: 세션당 보상형 광고 한도 도달 시 CTA 버튼 비활성화 + "다음 세션에서 다시 받을 수 있어요" 안내
3. **모든 스킨 해금 완료**: 3종 모두 해금 상태에서 보상 C 선택 시 랜덤 스킨 재해금 (타이머 리셋)
4. **동시 보상 요청**: 이미 보상 처리 중일 때 중복 클릭 방지
5. **시간대 변경**: 기기 시간대 변경 시 스킨 타이머가 UTC 기반으로 정상 동작
6. **감정 기록 없는 날**: 오늘 입력이 없는 경우 보상 B 선택 시 "오늘 기록된 감정이 없어요" 안내

## 품질 기준

| 항목 | 기준 |
|------|------|
| 보상형 광고 재생 | 30초, 중도 포기 시 보상 미지급 |
| 주간 리포트 생성 | 데이터 충분 시 1초 이내 |
| 키워드 추출 | 5개 키워드, 500ms 이내 |
| 스킨 해금 애니메이션 | 1.5초, Framer Motion |
| 보상 모달 영향 | 기존 report/idle 흐름에 영향 없음 |
| 상태 복원 | 앱 재시작 후 100ms 이내 |
