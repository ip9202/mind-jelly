## 인수 시나리오 (Acceptance Scenarios)

### AC-001: 젤리 캐릭터 렌더링

**우선순위:** High
**관련 요구사항:** REQ-UBI-002

```
Given Canvas가 초기화되고 Matter.js 엔진이 실행 중이다
When 애플리케이션이 로드된다
Then 젤리 캐릭터가 Canvas 중앙에 렌더링된다
And 젤리는 20-30개 정점의 Soft-body 형태를 유지한다
And 젤리 색상은 #FFD1DC이다
And 젤리에 backdrop-filter blur(8px) 효과가 적용된다
And 젤리 opacity는 0.85이다
And 젤리에 inset shadow가 표시된다
```

**검증 방법:**
- Canvas에 젤리 형태가 렌더링되는지 시각 확인
- 브라우저 개발자도구에서 Canvas 요소 확인
- 정점 수가 20-30 범위인지 로그 확인

### AC-002: 젤리 페이스 표정

**우선순위:** High
**관련 요구사항:** REQ-STA-001, REQ-STA-002, REQ-STA-003, REQ-STA-004

```
Given 젤리 캐릭터가 Canvas에 렌더링되어 있다
When 젤리 상태가 Idle이면
Then 눈이 "• •"으로 표시된다
And 입이 "o"으로 표시된다

When 젤리 상태가 Anticipation이면
Then 눈이 "• •" (약간 확대)으로 표시된다
And 입이 "o" (약간 확대)으로 표시된다

When 젤리 상태가 Eating이면
Then 눈이 "u u"으로 표시된다
And 입이 "o" (크게 벌림)으로 표시된다

When 젤리 상태가 Satisfied이면
Then 눈이 "^ ^"으로 표시된다
And 입이 "-"으로 표시된다
```

**검증 방법:**
- 각 상태에서 페이스 표식이 올바르게 표시되는지 시각 확인
- Zustand Devtools에서 상태 전이 확인

### AC-003: Idle 호흡 애니메이션

**우선순위:** High
**관련 요구사항:** REQ-STA-001

```
Given 젤리가 Idle 상태이고 Canvas에 렌더링되어 있다
When 시간이 경과한다
Then 젤리가 translateY(-12px) 3s ease-in-out infinite 애니메이션으로 부드럽게 상하 운동한다
And 애니메이션이 끊김 없이 반복된다
```

**검증 방법:**
- 젤리의 수직 위치 변화를 프레임별로 확인
- 애니메이션 주기가 3초인지 측정
- 최대 이동량이 12px인지 확인

### AC-004: 구슬 생성

**우선순위:** High
**관련 요구사항:** REQ-EVT-005

```
Given 애플리케이션이 실행 중이고 젤리가 Idle 상태이다
When 사용자가 "테스트 입력" 버튼을 클릭한다
Then 5-15개의 감정 구슬이 Canvas 상단에 생성된다
And 각 구슬은 12px, 18px, 24px 중 랜덤한 크기를 가진다
And 구슬이 Pop-in 애니메이션(scale 0->1, 300ms)으로 나타난다
And 젤리가 Idle에서 Anticipation 상태로 전이한다
```

**검증 방법:**
- 버튼 클릭 후 Canvas에 구슬이 나타나는지 확인
- 구슬 수가 5-15 범위인지 확인 (여러 번 테스트)
- 구슬 크기가 세 가지 중 하나인지 확인
- Pop-in 애니메이션이 300ms 내 완료되는지 확인
- Zustand 상태가 anticipation으로 변경되는지 확인

### AC-005: 구슬 드래그 앤 드롭

**우선순위:** High
**관련 요구사항:** REQ-EVT-001

```
Given 구슬이 Canvas에 존재한다
When 사용자가 구슬을 터치/클릭한다
Then 가장 가까운 구슬이 선택된다 (20px 이내)

When 사용자가 드래그한다
Then 선택된 구슬이 포인터를 따라 이동한다
And 물리 시뮬레이션이 적용된다 (관성, 속도)

When 사용자가 구슬을 놓는다
Then 구슬이 dynamic 상태로 복귀한다
And 구슬이 마지막 속도에 따라 자연스럽게 이동한다
```

**검증 방법:**
- 터치/클릭으로 구슬이 선택되는지 확인
- 드래그 중 구슬이 포인터를 따라오는지 확인
- 릴리즈 후 관성 운동이 자연스러운지 확인
- 터치와 마우스 모두에서 동작하는지 확인

### AC-006: 자기장 효과

**우선순위:** High
**관련 요구사항:** REQ-EVT-002, REQ-STA-005

```
Given 구슬이 Canvas에 존재하고 젤리가 Anticipation 상태이다
When 구슬이 젤리 중심 50px 반경 내에 위치한다
Then 자기장 인력이 적용된다
And 구슬이 젤리 중심 방향으로 끌려간다
And 인력 크기는 거리에 반비례한다
And 자기장 영역이 시각적으로 표시된다 (반투명 원)
```

**검증 방법:**
- 50px 반경 내 구슬이 젤리 방향으로 이동하는지 확인
- 가까운 구슬일수록 더 빠르게 끌려가는지 확인
- 50px 반경 밖의 구슬은 영향받지 않는지 확인
- 자기장 시각화가 표시되는지 확인

**관련 요구사항:** REQ-EVT-003, REQ-STA-003


**검증 방법:**
- 구슬이 젤리에 닿으면 사라지는지 확인

- 충돌 후 구슬이 물리 월드에서 제거되는지 확인
- 카운트가 올바르게 증가하는지 확인

### AC-010: Canvas 영역 이탈 방지 및 강한 반사

**우선순위:** High
**관련 요구사항:** REQ-UNW-003

```
Given Canvas가 초기화되고 구슬이 존재한다
When 구슬이 Canvas 경계에 도달한다
Then 구슬이 벽면에서 강하게 반사된다
And 구슬이 Canvas 영역 밖으로 나가지 않는다
And 벽면 Restitution은 0.8이다 (강한 반발력으로 튕겨져 나옴)
And 반사 후 구슬이 반대편까지 도달할 수 있는 충분한 속도를 유지한다
```

**검증 방법:**
- 구슬이 화면 밖으로 나가지 않는지 확인
- 벽면 충돌 시 강하게 반사되는지 확인 (Restitution 0.8 적용)
- 반사 후 구슬이 반대편 벽 근처까지 도달하는지 확인
- 여러 방향에서 벽면 충돌 테스트

**우선순위:** High
**관련 요구사항:** REQ-UNW-001

**검증 방법:**

- 15개 구슬 + 25개 정점 상태에서 30초간 fps 모니터링
- 드래그 중 fps가 30 이하로 떨어지지 않는지 확인
