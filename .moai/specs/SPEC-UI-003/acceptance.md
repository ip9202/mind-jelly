## 1. Functional Acceptance Criteria

### AC-001: 카드 간소화 -- 표시 요소 제한

**Given** 홈 화면에 감정 리포트 카드가 표시되어 있을 때
**When** 카드를 확인하면
**Then** 감정 페이스, summary 메시지, 조언 메시지만 표시된다

### AC-002: 카드 간소화 -- 요소 제거

**Given** 감정 리포트 카드에 표시될 데이터가 있을 때
**When** 카드를 확인하면
**Then** 상위 감정 순위, 스트릭, 패턴 변화가 표시되지 않는다

### AC-003: 카드 간소화 -- 빈 데이터

**Given** 기록된 감정 데이터가 없을 때
**When** 카드를 확인하면
**Then** 기본 감정 페이스와 빈 데이터 안내 메시지가 표시된다

### AC-004: 바텀시트 -- 인사이트 탭 존재

**Given** 감정 통계 바텀시트가 열려 있을 때
**When** 탭 네비게이션을 확인하면
**Then** "트렌드", "도넛", "인사이트" 3개의 탭이 표시된다

### AC-005: 바텀시트 -- 인사이트 탭 내용

**Given** 감정 데이터가 있을 때
**When** 인사이트 탭을 선택하면
**Then** 상위 감정 순위(1~3위, 감정 라벨 + 백분율), 스트릭(연속 일수), 패턴 변화(트렌드 메시지)가 표시된다

### AC-006: 바텀시트 -- 인사이트 탭 빈 데이터

**Given** 감정 데이터가 없을 때
**When** 인사이트 탭을 선택하면
**Then** 빈 데이터 안내 메시지가 표시된다

### AC-007: 바텀시트 -- 탭 전환

**Given** 바텀시트가 열려 있을 때
**When** 트렌드 -> 도넛 -> 인사이트 순서로 탭을 전환하면
**Then** 각 탭에 해당하는 콘텐츠가 정상적으로 교체되어 표시된다

## 2. Quality Acceptance Criteria

### AC-008: 기존 테스트 통과

**Given** 기존 테스트 스위트가 있을 때
**When** `vitest run`을 실행하면
**Then** 모든 테스트가 통과한다

### AC-009: 새로운 테스트 작성

**Given** 인사이트 탭이 추가되었을 때
**When** 테스트를 확인하면
**Then** 인사이트 탭 렌더링, 탭 전환, 빈 데이터 상태에 대한 테스트가 존재한다

### AC-010: 정적 분석 통과

**Given** 코드 변경이 완료되었을 때
**When** TypeScript 컴파일과 ESLint를 실행하면
**Then** 에러가 없다

## 3. UI/UX Acceptance Criteria

### AC-011: 카드 높이 최적화

**Given** 개인화 인사이트 섹션이 제거되었을 때
**When** 홈 화면을 확인하면
**Then** 카드 높이가 기존 대비 눈에 띄게 축소되어 한 화면에 더 많은 콘텐츠가 보인다

### AC-012: 디자인 일관성

**Given** 인사이트 탭이 표시되었을 때
**When** 시각적 요소를 확인하면
**Then** 기존 바텀시트 탭과 동일한 버튼 스타일, 감정별 색상, 아이콘이 적용되어 있다

### AC-013: 접근성

**Given** 인사이트 탭이 있을 때
**When** 접근성 검사를 수행하면
**Then** 탭 버튼에 `aria-pressed` 속성이 설정되어 있고, 콘텐츠에 적절한 `aria-label`이 적용되어 있다

## 4. Edge Cases

| Case | Expected Behavior |
|------|-------------------|
| topEmotions가 빈 배열 | 상위 감정 섹션이 렌더링되지 않음 |
| streak이 0 | 스트릭 섹션이 렌더링되지 않음 |
| patternChange가 null | 패턴 변화 섹션이 렌더링되지 않음 |
| 바텀시트 열 때 기본 탭 | 기존대로 'trend' 탭이 기본 선택 |
| 감정 키가 유효하지 않은 값 | safeEmotionKey가 기본값으로 대체 (기존 로직 유지) |

---

## 5. Definition of Done

- [ ] 모든 Functional AC (AC-001 ~ AC-007) 통과
- [ ] 모든 Quality AC (AC-008 ~ AC-010) 통과
- [ ] 모든 UI/UX AC (AC-011 ~ AC-013) 통과
- [ ] Edge Cases 전부 확인
- [ ] TypeScript 에러 0건
- [ ] ESLint 에러 0건
- [ ] 기존 테스트 회귀 없음
- [ ] 새로운 테스트 커버리지 충족
