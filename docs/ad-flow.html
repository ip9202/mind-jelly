광고 컴포넌트 개요

🎬
전면형 광고
사용 중 InterstitialAd

감정 표현 직후 satisfied 상태에서 report 전환 전에 전체 화면 광고 노출. 5초 후 스킵 버튼 활성화.

위치: src/components/ads/InterstitialAd.tsx

📏
배너 광고
사용 중 BannerAd

감정 리포트 화면(uiState === 'report') 하단에 320x50 배너 노출. 리포트 카드와 함께 표시.

위치: src/components/ads/BannerAd.tsx

🎁
보상형 광고
미사용 RewardedAdModal

광고 시청 후 보상 선택 (주간 리포트 / 감정 키워드 / 젤리 스킨). 컴포넌트는 구현 완료, 페이지에 미연결.

위치: src/components/ads/RewardedAdModal.tsx

사용자 유형 판별 조건 전면광고 한도 배너광고
신규 (new) sessionCount < 3 0회/일 (전면광고 없음) 리포트 화면에서만 노출
일반 (normal) sessionCount >= 3 + todaySession < 5 최대 1회/일 리포트 화면에서만 노출
헤비 (heavy) todaySession >= 5 최대 2회/일 리포트 화면에서만 노출

광고 노출 타임라인

감정 표현 1회 사이클에서 광고가 등장하는 시점

1. 사용자 감정 선택
홈 화면(idle) → 감정 입력(input)
2. 젤리 애니메이션
restoring → beads: 구슬이 생성되고 젤리가 감정을 흡수
3. 모든 구슬 먹음 (satisfied)
마지막 구슬 충돌 후 500ms 뒤 satisfied 상태 전이
4. 전면형 광고 노출 (조건부)
canShowInterstitial() 통과 시 전면광고 표시. 5초 뒤 스킵 버튼 활성화. 사용자가 닫으면 다음 단계 진행.
5. 감정 리포트 + 배너광고
satisfied 상태 3초(SATISFIED_DISPLAY_MS) 유지 후 report 전환. 리포트 카드 + 배너광고 동시 노출.
6. 홈으로 복귀
리포트 확인 후 idle 상태로 복귀. 다음 사이클 시작.

전면형 광고 (InterstitialAd) 상세

sequenceDiagram participant U as 사용자 participant P as HomePage participant F as adFrequencyControl participant A as InterstitialAd participant SDK as GoogleAdMob SDK U->>P: 감정 표현 (beads → satisfied) P->>F: canShowInterstitial() F->>F: getUserType() → new/normal/heavy F-->>P: true / false alt 광고 가능 (true) P->>A: 렌더링 시작 A->>SDK: loadAppsInTossAdMob() SDK-->>A: loaded 이벤트 A->>SDK: showAppsInTossAdMob() SDK-->>A: requested 이벤트 A->>F: recordAdShown() Note over U,SDK: 전면광고 표시 중 (5초) SDK-->>A: dismissed 이벤트 A->>P: onClosed() else 광고 불가 (false) Note over P: 광고 없이 report로 진행 end P->>P: setUiState('report')
참고: 전면광고는 satisfied 감지 후 setTimeout(..., 0)으로 즉시 큐에 등록됩니다. 실제 report 전환은 SATISFIED_DISPLAY_MS(3초) 후 발생합니다.

보상형 광고 (RewardedAd) - 미사용 (인프라 완성)

보상형 광고란? 사용자가 광고를 끝까지 시청하면 보상을 받는 형태입니다. 일반 광고와 달리 사용자가 직접 선택해서 보는 것이고, 끝까지 봐야만 보상이 지급됩니다. 중간에 닫으면 보상이 없습니다.

왜 보상형 광고가 수익이 더 높은가? 광고주 입장에서 사용자가 광고를 끝까지 시청하는 것이 보장되므로, 일반 노출 광고보다 단가가 5~10배 높습니다. 특히 젤리 스킨 같은 한정판 보상은 사용자가 광고를 피하지 않고 능동적으로 시청하게 만드는 핵심 수단입니다.
연결 필요: RewardedAdModal을 리포트 화면이나 설정 페이지에 연결하면 즉시 사용 가능합니다. rewardStore에 canShowRewardedAd, incrementRewardedAdCount 로직도 이미 준비되어 있습니다.
