## 배경

### 그라데이션

```
linear-gradient(135deg, #E6E6FA 0%, #FFD1DC 50%, #FFE5D9 100%)
```

- 라벤더에서 핑크, 피치로 부드럽게 전환
- `background-size: 400% 400%` 로 넉넉하게 설정
- 15초 주기로 그라데이션 위치가 천천히 이동하는 애니메이션 적용

### 배경 장식 요소

- **구름**: 매우 낮은 투명도(~20%)의 부드러운 구름 형태 3-4개, 천천히 우에서 좌로 드리프트
- **별 스파클**: 작은 별 모양 요소들이 무작위 위치에서 반짝임 (opacity 0.3 ~ 1.0)
- **비네팅**: 화면 가장자리에 부드러운 그라데이션 오버레이로 시선을 중앙으로 유도

## 젤리 캐릭터

### 기본 형태

| 속성 | 값 |
|------|-----|
| 바디 색상 | `#FFD1DC` (Soft Pink) |
| 외곽선 | `#FFB6C1` (Rose Blush), 2px |
| 크기 | 반지름 40px (캔버스 기준) |
| 형태 | 둥근 원형 (물리 엔진으로 자연스러운 움직임) |
| 글로우 | `box-shadow: 0 0 40px rgba(255, 209, 220, 0.5)` |
| 내부 하이라이트 | `inset 0 0 40px rgba(255, 255, 255, 0.6)` (유리질 느낌) |

### 표정 상태 (4가지)

**1. Idle (기본)**
- 눈: 작은 점 2개 (• •), 위치: 중앙에서 좌우 -10px, 위쪽 -5px, 반지름 3px, 색상 `#333`
- 입: 작은 원, 중앙 아래 +8px, 반지름 4px, 색상 `#333`
- 애니메이션: 부드러운 떠오르기 (translateY 0 ~ -15px, 4초 루프)

**2. Anticipation (기대)**
- 눈: 점 (동일 위치)
- 입: 타원, rx=5 ry=3+애니메이션값, 색상 `#333`
- 몸이 살짝 앞으로 기울어짐

**3. Eating (먹는 중)**
- 눈: 점 (동일)
- 입: 큰 타원, rx=8 ry=6+애니메이션값*2, 색상 `#FF6B6B` (Coral Red)
- 몸이 살짝 눌림

**4. Satisfied (만족)**
- 눈: 점 (동일)
- 입: 부드러운 곡선 미소 `M -8 8 Q 0 14 8 8`, stroke `#333`, 2px
- 볼터치 추가 가능

## 애니메이션

### 젤리 애니메이션

| 상태 | 애니메이션 | 시간 | 이징 |
|------|-----------|------|------|
| Idle | 부드러운 떠오르기 (translateY 0 ~ -15px) | 4초 루프 | ease-in-out |
| Idle 대기 | 호흡 (scale 0.98 ~ 1.02) | 3초 루프 | ease-in-out |
| Anticipation | 앞으로 기울임, 눈 커짐 | 0.5s | spring |
| Eating | 입 벌림, 몸 살짝 눌림 | 0.8s | ease-out |
| Satisfied | 행복한 흔들림, 볼터치 | 1s | spring |

### 구슬 애니메이션

| 이벤트 | 애니메이션 | 시간 |
|--------|-----------|------|
| 생성 | 0에서 1로 스케일업 + 스파클 | 0.4s |
| 떠오르기 | translateY ±3px | 2초 루프 |
| 먹힘 | 1에서 0으로 스케일다운 + 파티클 | 0.3s |
| 호버 | 1.1배 확대 + 글로우 | 0.2s |

### UI 전환

| 전환 | 애니메이션 | 시간 |
|------|-----------|------|
| 페이지 진입 | 위로 슬라이드 + 페이드인 | 0.4s |
| 페이지 퇴장 | 아래로 슬라이드 + 페이드아웃 | 0.3s |
| 바텀시트 열림 | 아래에서 슬라이드업 | 0.3s |
| 바텀시트 닫힘 | 아래로 슬라이드다운 | 0.2s |
| 토스트 인 | 위에서 슬라이드다운 | 0.3s |
| 토스트 아웃 | 위로 슬라이드 + 페이드 | 0.3s |

## Stitch 구현 시 참고사항

1. **폰트**: Dongle, Gowun Dodum, Gamja Flower - 모두 Google Fonts 제공
2. **모바일 우선**: 375px 너비로 디자인 후 반응형 확장
3. **하단 네비게이션**: 모바일은 하단 탭바 (홈, 일기, 설정)
4. **터치 타겟**: 모든 버튼 최소 48px
5. **아이콘**: Material Design 기본 대신 커스텀 귀여운 아이콘 사용
6. **캔버스 영역**: 메인 인터랙션 영역은 젤리 캐릭터 일러스트로 플레이스홀더 표시
7. **바텀시트**: 표준 패턴 + 드래그 핸들 사용
8. **색상 모드**: 라이트 모드 우선, 다크 모드는 향후 추가
